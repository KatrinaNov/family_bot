# 🏠 Family Bot — Telegram-бот для семейного дежурства

Бот для организации дежурств в семье: утренние напоминания, список задач на день, подтверждение выполнения админом и автоматическое подтверждение в 23:00.

## Логика работы

### 1. Утреннее уведомление (09:00)
- Каждый день в 09:00 бот определяет текущего дежурного и список задач на сегодня (с учётом периодичности: daily, weekly, biweekly, custom).
- Отправляет сообщение:
  - «Доброе утро 🌞»
  - «Сегодня дежурный: &lt;имя&gt;»
  - Список задач
- Под сообщением кнопка: **✅ Задачи выполнены**.

### 2. Кнопка «Задачи выполнены»
- Нажимает только дежурный.
- Создаётся запись со статусом **pending confirmation**.
- Админу в чат отправляется сообщение: «Дежурный &lt;имя&gt; отметил задачи как выполненные. Подтвердить?» с кнопками **✅ Подтвердить** и **❌ Отклонить**.

### 3. Подтверждение админом
- Статус → **confirmed**, дежурному начисляются баллы.
- В чат: «Задачи подтверждены 👍 Баллы начислены».

### 4. Отклонение админом
- Статус снова **active**.
- В чат: «Задачи отклонены ❗ Нужно выполнить снова. Кнопка «Задачи выполнены» снова активна для дежурного.»

### 5. Авто-подтверждение в 23:00
- Если дежурный нажал «Задачи выполнены», но админ до 23:00 не подтвердил и не отклонил — задачи автоматически считаются выполненными, баллы начисляются.
- В чат: «Задачи автоматически засчитаны ✅ Баллы начислены.»

### 6. Динамический список задач
- Задачи хранятся с полями: **id**, **title**, **description**, **intervalType** (daily / weekly / biweekly / custom), **intervalValue**, **lastCompletedDate**, **points**.
- Бот сам определяет, какие задачи показывать сегодня.

### 7. Меню
- В чате появляется **клавиатура-меню** (не нужно вводить команды вручную):
  - **📋 Задачи** — список на сегодня и кнопка «Задачи выполнены» (если вы дежурный).
  - **👤 Дежурный** — кто дежурный сегодня.
  - **📊 Статистика** — очки, стрик, дежурства, подтверждено/отклонено/авто/пропуски, бейджи.
  - **🏆 Рейтинг** — таблица по очкам.
  - **⚙️ Админ** — админ-панель (доступ только админу).
  - **ℹ️ Помощь** — справка.

### 8. Админ (один на чат)
- В чате может быть только **один** админ. Назначение: `/setadmin` (нужно сначала `/join`).
- Админ может: добавить/удалить/редактировать задачи, сменить дежурного вручную.

### 9. Стрики и бейджи
- **Стрик** (`streak`) увеличивается на +1 каждый раз, когда дежурство **засчитано** (подтверждено админом или авто-подтверждено в 23:00).
- **Стрик сбрасывается в 0**, если админ **отклонил** дежурство, или если дежурный **не отметил** выполнение до конца дня (на следующий день это фиксируется как пропуск).
- **Бейджи по очкам** (`badges`) пересчитываются по порогам из `config.js` после каждого начисления/изменения очков.
- **Стрик-бейджи** (`streakBadges`) выдаются по порогам стрика из `config.js`.

## Установка и запуск

1. Клонировать репозиторий и установить зависимости:
   ```bash
   npm install
   ```

2. Создать файл `.env` на основе `.env.example`:
   ```bash
   cp .env.example .env
   ```
   Указать в `.env`:
   - `BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather).

3. Запуск:
   ```bash
   npm start
   ```

4. В группе (или личке) написать боту `/start`, затем каждый участник — `/join`. Админ назначается командой `/setadmin` (в чате может быть только один админ).

**Важно:** должен быть запущен **только один** процесс бота. Иначе возможна ошибка 409 (conflict getUpdates).

## Cron-задачи

| Время | Задача |
|--------|--------|
| 09:00  | Утреннее уведомление: дежурный + список задач + кнопка «Задачи выполнены». |
| 23:00  | Авто-подтверждение: все дежурства со статусом «pending confirmation» переводятся в «confirmed», начисляются баллы. |

Часовой пояс задаётся в `config.js` (`timezone: "Europe/Minsk"`).

## Защита и надёжность

- **Один процесс** — избегаем 409 при polling.
- **Idempotent-обработчики** — повторное нажатие «Задачи выполнены» не создаёт дубликаты (статус уже `pending_confirmation`).
- **Состояние в data.json** — после перезапуска бота данные сохраняются.
- **Логирование** — в консоль (уровни INFO/WARN/ERROR); при `DEBUG=1` — DEBUG.
- **Обработка ошибок** — try/catch в обработчиках, ответ пользователю при сбоях.
